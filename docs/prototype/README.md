# Interactive prototype

`eom-tasks.html` is a single-file, browser-only prototype of the app (no server, no database): the three role
dashboards, add-task, Admin menu, invoicing wizard, approval sheet, payments, requests, attendance, inventory,
vault, expenses and settings, with sample data kept in `localStorage`.

It is published as a claude.ai artifact for quick try-outs on a phone. It is **not** the app: the real product
lives in `src/` and runs via Docker / Render (see the root README).
